Test suite · Nov 2026

Toolshop checkout: UI, API and load tests

Playwright, Postman and k6 tests for an online shop's checkout, from cart to invoice.

Found: the full card number and CVV returned in plain text by the invoice API, one of 19 defects reported.

How it's built
  • The end-to-end test reads the invoice back through the API, so it proves the order was saved.
  • Each open defect is a test.fail() test that goes red in CI when the bug is fixed.
  • k6 load runs against a local Docker copy, so the shared demo never takes load.
  • Built with my own Claude skills for test research, framework setup and run reports.
